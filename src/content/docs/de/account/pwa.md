solyto ist eine Progressive Web App (PWA). Das bedeutet, du kannst sie auf deinem Gerät installieren und wie eine native App nutzen — mit eigenem Fenster, ohne Browser-Symbolleiste und mit einem Icon auf deinem Startbildschirm oder in der Taskleiste.

## So installierst du solyto

### Über die Einstellungen

1. Gehe zu **Einstellungen → App**
2. Klicke auf **Install App**
3. Bestätige die Installationsaufforderung

### Über den Browser

Die meisten Browser zeigen automatisch eine Installationsaufforderung an, wenn du solyto besuchst. Halte Ausschau nach dem Installations-Symbol in der Adressleiste oder im Browsermenü.

### Desktop (Chrome / Edge)

1. Rufe deine solyto-Instanz in Chrome oder Edge auf
2. Klicke auf das Installations-Symbol in der Adressleiste (oder **Menü → solyto installieren**)
3. Die App öffnet sich in einem eigenen Fenster

### Mobil (Chrome / Safari)

**Android (Chrome):**
1. Rufe deine solyto-Instanz auf
2. Tippe auf das Browsermenü (drei Punkte)
3. Tippe auf **Zum Startbildschirm hinzufügen** oder **App installieren**

**iOS (Safari):**
1. Rufe deine solyto-Instanz auf
2. Tippe auf die Schaltfläche **Teilen**
3. Tippe auf **Zum Home-Bildschirm**

## Standalone-Modus

Nach der Installation läuft solyto im Standalone-Modus — ohne Browser-Adressleiste, ohne Tabs, ohne Browser-Oberfläche. Es sieht aus und fühlt sich an wie eine native App.
