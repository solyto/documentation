solyto ist Open Source und wird von seiner Community mitgestaltet. So kannst du dich beteiligen.

## GitHub

Der gesamte solyto-Code liegt auf GitHub unter [github.com/solyto](https://github.com/solyto). Die wichtigsten Repositories sind:

- **[app](https://github.com/solyto/app)** — das SvelteKit-Frontend
- **[api](https://github.com/solyto/api)** — das Laravel-Backend
- **[selfhosted](https://github.com/solyto/selfhosted)** — Docker-Compose-Stack für Self-Hosting
- **[localdocker](https://github.com/solyto/localdocker)** — lokale Entwicklungsumgebung
- **[documentation](https://github.com/solyto/documentation)** — diese Dokumentations-Website

### Probleme melden

Einen Fehler gefunden oder einen Feature-Wunsch? Erstelle ein Issue im passenden Repository. Bitte gib Folgendes an:

- Schritte zur Reproduktion (bei Fehlern)
- Erwartetes vs. tatsächliches Verhalten
- Dein Setup (gehostet, lokal oder self-hosted)
- Browser und Version (falls zutreffend)

### Beitragen

Beiträge sind willkommen — ob Code, Dokumentation, Übersetzungen oder Design. Forke das jeweilige Repository, erstelle einen Branch und öffne einen Pull Request.

## Discord

Tritt dem [solyto-Discord-Server](https://discord.gg/REyWQKgUcq) bei, um:

- Fragen zu stellen und Hilfe zu bekommen
- Feedback und Ideen zu teilen
- Dich mit anderen Nutzern und den Entwicklern auszutauschen
- Auf dem Laufenden über neue Releases und Funktionen zu bleiben
