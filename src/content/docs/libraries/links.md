The Link Library is a personal bookmark manager. Save URLs with descriptions, tags, and notes.

## Adding links

- Add manually via the + button
- Send a URL to the [Telegram Bot](/integrations/telegram/) — it's automatically saved to your library
- Save directly from the [Feeds](/features/feeds/) reader

## Entry fields

- URL and title
- Description
- Tags
- Notes

## Exporting

Exports as `.html` in the Netscape Bookmark Format, which every browser can import. See [Exporting Data](/integrations/exporting/).
