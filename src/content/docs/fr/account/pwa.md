---
title: Installer en tant qu'application (PWA)
description: Installez solyto comme application autonome sur ordinateur et mobile.
---

solyto est une application web progressive (PWA). Cela signifie que vous pouvez l'installer sur votre appareil et l'utiliser comme une application native — avec sa propre fenêtre, sans barre d'outils de navigateur, et une icône sur votre écran d'accueil ou votre barre des tâches.

## Comment l'installer

### Depuis les paramètres

1. Allez dans **Paramètres → Application**
2. Cliquez sur **Installer l'application**
3. Confirmez l'invite d'installation

### Depuis le navigateur

La plupart des navigateurs affichent automatiquement une invite d'installation lorsque vous visitez solyto. Recherchez l'icône d'installation dans la barre d'adresse ou le menu du navigateur.

### Ordinateur (Chrome / Edge)

1. Visitez votre instance solyto dans Chrome ou Edge
2. Cliquez sur l'icône d'installation dans la barre d'adresse (ou **Menu → Installer solyto**)
3. L'application s'ouvre dans sa propre fenêtre

### Mobile (Chrome / Safari)

**Android (Chrome) :**
1. Visitez votre instance solyto
2. Appuyez sur le menu du navigateur (trois points)
3. Appuyez sur **Ajouter à l'écran d'accueil** ou **Installer l'application**

**iOS (Safari) :**
1. Visitez votre instance solyto
2. Appuyez sur le bouton **Partager**
3. Appuyez sur **Ajouter à l'écran d'accueil**

## Mode autonome

Une fois installé, solyto s'exécute en mode autonome — sans barre d'adresse, sans onglets, sans interface de navigateur. L'application ressemble à une application native et se comporte comme telle.
