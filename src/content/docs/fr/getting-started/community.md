solyto est open source et développé par sa communauté. Voici comment vous impliquer.

## GitHub

Tout le code de solyto se trouve sur GitHub à l'adresse [github.com/solyto](https://github.com/solyto). Les principaux dépôts sont :

- **[app](https://github.com/solyto/app)** — le frontend SvelteKit
- **[api](https://github.com/solyto/api)** — le backend Laravel
- **[selfhosted](https://github.com/solyto/selfhosted)** — la pile Docker Compose pour l'auto-hébergement
- **[localdocker](https://github.com/solyto/localdocker)** — l'environnement de développement local
- **[documentation](https://github.com/solyto/documentation)** — ce site de documentation

### Signaler un problème

Vous avez trouvé un bug ou souhaitez proposer une fonctionnalité ? Ouvrez un ticket (issue) sur le dépôt concerné. Merci d'inclure :

- Les étapes pour reproduire le problème (pour les bugs)
- Le comportement attendu et le comportement observé
- Votre configuration (hébergé, local, ou auto-hébergé)
- Le navigateur et sa version (le cas échéant)

### Contribuer

Toutes les contributions sont les bienvenues — code, documentation, traductions ou design. Forkez le dépôt concerné, créez une branche, puis ouvrez une pull request.

## Discord

Rejoignez le [serveur Discord de solyto](https://discord.gg/REyWQKgUcq) pour :

- Poser des questions et obtenir de l'aide
- Partager vos retours et vos idées
- Discuter avec d'autres utilisateurs et les développeurs
- Rester informé des nouvelles versions et fonctionnalités
