solyto prend en charge quatre langues d'interface. Changez de langue dans **Paramètres → Localisation**.

## Changer de langue

1. Allez dans **Paramètres → Localisation**
2. Sélectionnez votre langue préférée dans la liste déroulante **Langue**
3. L'interface se met à jour immédiatement

## Langues disponibles

- **Anglais** (en)
- **Allemand** (de)
- **Français** (fr)
- **Espagnol** (es)

La langue est choisie lors de l'inscription et détectée automatiquement à partir de votre navigateur dans les autres cas. Le bot Telegram et les autres intégrations suivent le paramètre de langue de votre compte.

## Contribuer aux traductions

Si une traduction est manquante ou incomplète, les contributions sont les bienvenues. Les fichiers de traduction se trouvent dans le [dépôt de l'application](https://github.com/solyto/app), sous `src/lib/i18n/`.
