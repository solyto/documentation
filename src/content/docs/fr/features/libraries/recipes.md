La Bibliothèque de recettes est l'endroit où vous rassemblez les recettes que vous avez essayées ou souhaitez essayer. Enregistrez les ingrédients, les étapes et les types de repas — tout ce dont vous avez besoin pour cuisiner, organisé au même endroit.

## Ajouter des recettes

Ajoutez des recettes à votre bibliothèque de deux façons :

- **Saisie manuelle** — remplissez les détails vous-même
- **Import Chefkoch** — collez une URL Chefkoch pour importer automatiquement la recette

### Import depuis Chefkoch

Collez une URL de recette Chefkoch et solyto récupère automatiquement le titre, les ingrédients, la description et d'autres détails. Aucune retranscription n'est nécessaire — collez simplement le lien et confirmez.

Consultez [Importation des données](/integrations/importing/) pour plus de détails.

## Champs d'une entrée

Chaque entrée de recette comprend :

| Champ | Description |
|-------|-------------|
| **title** | Nom de la recette |
| **rating** | 1 à 5 étoiles |
| **type** | Type de repas (petit-déjeuner, déjeuner, dîner, en-cas, dessert, boisson, autre) |
| **time_to_make** | Temps total de préparation et de cuisson |
| **calories** | Nombre de calories |
| **servings** | Nombre de portions que produit la recette |
| **kcal per serving** | Calculé automatiquement à partir des calories et des portions |
| **ingredients** | Liste structurée — chaque ingrédient a un nom, une quantité et une unité |
| **steps** | Liste ordonnée des étapes de préparation |
| **description** | Courte description ou notes de méthode |
| **cover** | Photo du plat terminé |
| **link** | URL vers la recette originale |

## Types de recette

Classez les recettes par type de repas :

- **Petit-déjeuner** — repas matinaux et brunch
- **Déjeuner** — plats de midi
- **Dîner** — plats principaux et repas du soir
- **En-cas** — petites bouchées et amuse-gueules
- **Dessert** — sucreries et pâtisseries
- **Boisson** — boissons, smoothies, cocktails
- **Autre**

## Vues et filtres

Parcourez vos recettes en vues **Liste** ou **Cartes**. La recherche porte sur le **titre ou le nom des ingrédients** de la recette (appuyez sur **Ctrl+F**), et vous pouvez filtrer par type ou par note.

## Exportation

Exportez toute votre bibliothèque de recettes au format `.csv`. Le fichier inclut tous les champs — titre, ingrédients, étapes, temps et note. Consultez [Exportation des données](/integrations/exporting/).
