La Bibliothèque de jeux suit à la fois les jeux vidéo et les jeux de société. Gardez une trace de ce que vous possédez, ce à quoi vous jouez, ce que vous avez terminé, et ce à quoi vous voulez jouer ensuite.

## Ajouter des jeux

Ajoutez des jeux à votre bibliothèque de deux façons :

- **Saisie manuelle** — remplissez les détails vous-même
- **Recherche / import** — recherchez sur Steam ou BoardGameGeek par titre, ou collez une URL Steam/BGG pour importer automatiquement les détails, la jaquette et les métadonnées

Consultez [Importation des données](/integrations/importing/) pour des instructions détaillées.

## Champs d'une entrée

Chaque entrée de jeu comprend :

| Champ | Description |
|-------|-------------|
| **title** | Titre du jeu |
| **platform** | PC, PlayStation, Xbox, Nintendo, mobile, jeu de société, ou autre |
| **rating** | 1 à 5 étoiles |
| **publication_year** | Année de sortie du jeu |
| **developer** | Studio ou concepteur du jeu |
| **publisher** | Nom de l'éditeur |
| **playtime_hours** | Heures jouées |
| **completed** | Si vous avez terminé le jeu |
| **cover** | Jaquette ou boîte du jeu |
| **link** | URL (Steam, BGG, page boutique) |
| **wishlist** | Marquer comme envie de jouer |
| **started_at** | Date à laquelle vous avez commencé à jouer |
| **finished_at** | Date à laquelle vous avez terminé de jouer |
| **tags** | Étiquettes colorées pour le filtrage |
| **genres** | Un ou plusieurs genres de jeu |

## Plateformes

Les jeux peuvent être étiquetés avec une plateforme :

- **PC** — Windows, Linux, Mac
- **PlayStation** — PS4, PS5
- **Xbox** — Xbox One, Xbox Series
- **Nintendo** — Switch, 3DS
- **Mobile** — iOS, Android
- **Jeu de société** — jeux de table physiques
- **Autre**

## Genres de jeu

La bibliothèque de jeux dispose de son propre système de genres. Ajoutez des genres correspondant à votre collection — RPG, stratégie, FPS, coopératif, deck builder, ou tout autre. Assignez plusieurs genres à un même jeu.

Gérez les genres depuis les paramètres de la bibliothèque. Vous pouvez ajouter, renommer et supprimer des genres à tout moment.

## Suivi du temps de jeu

Enregistrez votre temps de jeu en heures pour chaque jeu. Le temps de jeu est affiché dans la liste des jeux et sur la page de détail de chaque jeu. Suivez le temps que vous avez investi dans votre collection.

## Statut de complétion

Marquez les jeux comme **terminés** une fois que vous les avez finis. Ce champ booléen vous aide à distinguer les jeux terminés de ceux encore en cours ou abandonnés. Filtrez par statut de complétion pour voir ce qu'il vous reste à jouer.

## Vues et filtres

Parcourez votre collection de jeux en vues **Liste** ou **Cartes**. Recherchez par titre, développeur ou éditeur (appuyez sur **Ctrl+F**), et filtrez par genre, note ou liste de souhaits.

## Exportation

Exportez toute votre bibliothèque de jeux au format `.csv`. Le fichier inclut tous les champs — titre, plateforme, note, temps de jeu et plus. Consultez [Exportation des données](/integrations/exporting/).
