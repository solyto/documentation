---

The Contacts feature is a full address book, with optional two-way sync to any CardDAV-compatible service.

## Adding contacts

Create contacts with:

- Name, photo, and birthday
- Phone numbers, email addresses, and websites
- Postal addresses
- Notes
- Custom fields

## CardDAV sync

solyto supports two-way CardDAV sync, keeping your contacts in sync with:

- Google Contacts
- Apple Contacts
- Nextcloud Contacts
- Any CardDAV-compatible service

See [DAV Sync](/integrations/dav-sync/) for setup instructions.

## Search and filtering

Search contacts by name, email, or phone number. Filter by tags or groups.

## Exporting

Your contacts can be exported as a `.vcf` (vCard) file for import into any contacts app. See [Exporting Data](/integrations/exporting/).
