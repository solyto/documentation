---
title: Time Tracking
description: Track time on projects with a built-in Pomodoro timer.
---

The Time Tracking feature lets you log time against projects and tasks. It includes a built-in Pomodoro timer for focused work sessions.

## Logging time

Start a timer manually or enter time retroactively. Each entry includes:

- Project
- Description
- Start and end time (or duration)
- Tags

## Pomodoro timer

The Pomodoro timer runs a 25-minute focused session, followed by a 5-minute break. After four sessions, take a longer break.

- Start, pause, and stop from anywhere in the app
- Active session shown on the dashboard
- Configurable session and break durations in **Settings → Time Tracking**

## Reports

View logged time by project, tag, or date range. See totals per day, week, or month.

## Exporting

Time tracking data exports as `.csv` in a standard timesheet format. See [Exporting Data](/integrations/exporting/).
