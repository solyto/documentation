The Recipe Library is where you collect recipes you've tried or want to try. Save ingredients, steps, and meal types — everything you need to cook, organized in one place.

## Adding recipes

Add recipes to your library in two ways:

- **Manual entry** — fill in the details yourself
- **Chefkoch import** — paste a Chefkoch URL to auto-import the recipe

### Import from Chefkoch

Paste a Chefkoch recipe URL and solyto pulls in the title, ingredients, description, and other details automatically. No need to retype anything — just paste the link and confirm.

See [Importing Data](/integrations/importing/) for details.

## Entry fields

Each recipe entry includes:

| Field | Description |
|-------|-------------|
| **title** | Recipe name |
| **rating** | 1–5 stars |
| **time_to_make** | Total time to prepare and cook |
| **description** | Instructions or method |
| **ingredients** | List of ingredients |
| **type** | Meal type (breakfast, lunch, dinner, snack, dessert, drink) |
| **cover_image** | Photo of the finished dish |
| **link** | URL to the original recipe |
| **tags** | Colored tags for filtering |
| **notes** | Free-text notes (tips, modifications, etc.) |

## Recipe types

Categorize recipes by meal type:

- **Breakfast** — morning meals and brunch
- **Lunch** — midday dishes
- **Dinner** — main courses and evening meals
- **Snack** — small bites and appetizers
- **Dessert** — sweets and baked goods
- **Drink** — beverages, smoothies, cocktails

Filter by type to find the right recipe for the right time of day.

## Views and sorting

Browse your recipes and sort by:

- Title (A–Z)
- Rating
- Time to make
- Meal type
- Date added

Filter by type, tags, or rating to find what you're looking for.

## Exporting

Export your entire recipe library as `.csv`. The file includes all fields — title, ingredients, time, rating, tags, and notes. See [Exporting Data](/integrations/exporting/).
