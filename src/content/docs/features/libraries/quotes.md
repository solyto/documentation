The Quote Library is a personal collection of quotes — from books, people, films, or wherever you encounter words that resonate. Keep them all in one searchable place.

## Adding quotes

Add quotes manually. Fill in the text, attribute it to an author, and optionally note where you found it.

## Entry fields

Each quote entry includes:

| Field | Description |
|-------|-------------|
| **summary** | Short title or label for the quote |
| **author** | Who said or wrote it |
| **quote** | The full quote text |
| **source** | Where you found it (book title, film, person, etc.) |
| **tags** | Colored tags for filtering |
| **notes** | Free-text notes (context, thoughts, etc.) |

## Random quote

solyto provides an API endpoint that returns a random quote from your library. This powers the **Inspiration** section on your dashboard — a different quote each time you visit.

The random quote rotates daily, giving you fresh words to start your day.

## Views and sorting

Browse your quotes and sort by:

- Author (A–Z)
- Summary
- Date added

Filter by tags or search by keyword to find a specific quote.

## Exporting

Export your entire quote library as `.csv`. The file includes all fields — quote text, author, source, tags, and notes. See [Exporting Data](/integrations/exporting/).
