The Notes feature (also called Notebook) is a full-featured note-taking tool with folder organization, rich text editing, and markdown support.

## Editor

Notes uses a rich text editor ([Tiptap](https://tiptap.dev/)) that supports both WYSIWYG and markdown input. You can switch modes per note.

Supported formatting:

- Headings (H1–H6)
- Bold, italic, strikethrough, code
- Bullet and numbered lists
- Tables
- Images (upload or URL)
- Links
- Code blocks
- Blockquotes
- Horizontal rules

## Folders

Organize notes into folders and subfolders. Drag and drop to reorganize.

## Search

Full-text search across all notes and folders.

## Exporting

Notes export as a ZIP of `.md` files, one file per note — compatible with Obsidian, Notion, and any markdown editor. See [Exporting Data](/integrations/exporting/).
