title: Calendar

The Calendar feature lets you create and manage events, with optional two-way sync to any CalDAV-compatible calendar service.

## Creating events

Click any day or time slot to create an event. Events support:

- Title, description, and location
- Start and end time (or all-day)
- Recurring schedules
- Calendar assignment (you can have multiple calendars)

## Multiple calendars

You can create multiple calendars and color-code them. Useful for separating personal, work, and family events.

## CalDAV sync

solyto supports two-way CalDAV sync. This means your events stay in sync with:

- Google Calendar
- Apple Calendar
- Nextcloud Calendar
- Any other CalDAV-compatible service

See [DAV Sync](/integrations/dav-sync/) for setup instructions.

## Notifications

You can receive notifications for upcoming events via Telegram, email, or browser push. See [Notifications](/customization/notifications/).

## Exporting

Your calendar can be exported as a `.ics` file for import into any calendar app. See [Exporting Data](/integrations/exporting/).
