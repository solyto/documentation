Topics are focused learning modules built into solyto. Each topic covers a specific subject in depth, as an interactive reference you can use alongside your practice.

## Available topics

### Guitar Theory

An interactive guitar theory reference covering:

- Notes on the fretboard
- Scales and modes
- Chord shapes and inversions
- Intervals and harmony

## Using Topics

Topics are self-contained — you don't need to enter any data. Open a topic and use it as a reference while practicing or studying.
