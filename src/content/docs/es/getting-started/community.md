solyto es de código abierto y está construido por su comunidad. Así es como puedes participar.

## GitHub

Todo el código de solyto vive en GitHub, en [github.com/solyto](https://github.com/solyto). Los repositorios principales son:

- **[app](https://github.com/solyto/app)** — el frontend en SvelteKit
- **[api](https://github.com/solyto/api)** — el backend en Laravel
- **[selfhosted](https://github.com/solyto/selfhosted)** — la pila de Docker Compose para self-hosting
- **[localdocker](https://github.com/solyto/localdocker)** — entorno de desarrollo local
- **[documentation](https://github.com/solyto/documentation)** — este sitio de documentación

### Reportar problemas

¿Encontraste un error o tienes una solicitud de función? Abre un issue en el repositorio correspondiente. Por favor incluye:

- Pasos para reproducir el problema (en el caso de errores)
- Comportamiento esperado frente al comportamiento real
- Tu configuración (hosted, local o self-hosted)
- Navegador y versión (si corresponde)

### Contribuir

Las contribuciones son bienvenidas, ya sea código, documentación, traducciones o diseño. Haz un fork del repositorio correspondiente, crea una rama y abre un pull request.

## Discord

Únete al [servidor de Discord de solyto](https://discord.gg/REyWQKgUcq) para:

- Hacer preguntas y obtener ayuda
- Compartir comentarios e ideas
- Conversar con otros usuarios y con los desarrolladores
- Mantenerte al día sobre nuevos lanzamientos y funciones
