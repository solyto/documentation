La Biblioteca de recetas es donde recopilas las recetas que has probado o que quieres probar. Guarda ingredientes, pasos y tipos de comida — todo lo que necesitas para cocinar, organizado en un mismo lugar.

## Añadir recetas

Añade recetas a tu biblioteca de dos formas:

- **Entrada manual** — rellena los detalles tú mismo
- **Importación de Chefkoch** — pega una URL de Chefkoch para importar la receta automáticamente

### Importar desde Chefkoch

Pega la URL de una receta de Chefkoch y solyto trae el título, los ingredientes, la descripción y otros detalles automáticamente. No necesitas volver a escribir nada — solo pega el enlace y confirma.

Consulta [Importar datos](/integrations/importing/) para más detalles.

## Campos de la entrada

Cada entrada de receta incluye:

| Campo | Descripción |
|-------|-------------|
| **title** | Nombre de la receta |
| **rating** | 1–5 estrellas |
| **type** | Tipo de comida (desayuno, almuerzo, cena, aperitivo, postre, bebida, otro) |
| **time_to_make** | Tiempo total de preparación y cocción |
| **calories** | Recuento de calorías |
| **servings** | Cuántas raciones da la receta |
| **kcal per serving** | Calculado automáticamente a partir de las calorías y las raciones |
| **ingredients** | Lista estructurada — cada ingrediente tiene un nombre, una cantidad y una unidad |
| **steps** | Lista ordenada de pasos de preparación |
| **description** | Descripción breve o notas sobre el método |
| **cover** | Foto del plato terminado |
| **link** | URL a la receta original |

## Tipos de receta

Clasifica las recetas por tipo de comida:

- **Desayuno** — comidas matutinas y brunch
- **Almuerzo** — platos de mediodía
- **Cena** — platos principales y comidas nocturnas
- **Aperitivo** — bocados pequeños y entrantes
- **Postre** — dulces y repostería
- **Bebida** — bebidas, batidos, cócteles
- **Otro**

## Vistas y filtros

Explora tus recetas en las vistas **Lista** o **Tarjetas**. La búsqueda coincide con el **título o los nombres de los ingredientes** de la receta (pulsa **Ctrl+F**), y puedes filtrar por tipo o valoración.

## Exportar

Exporta toda tu biblioteca de recetas como `.csv`. El archivo incluye todos los campos — título, ingredientes, pasos, tiempo y valoración. Consulta [Exportar datos](/integrations/exporting/).
