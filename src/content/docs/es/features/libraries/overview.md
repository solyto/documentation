Las bibliotecas son una función distintiva única de solyto — rastreadores de colecciones personales para las cosas que posees, lees, ves, juegas, cocinas y coleccionas. Cada biblioteca está diseñada específicamente para su tipo de contenido, pero todas comparten una interfaz coherente para que siempre sepas moverte por ella.

## Bibliotecas disponibles

solyto incluye ocho bibliotecas:

| Biblioteca | Qué controlas |
|---------|---------------|
| [Biblioteca de música](/features/libraries/music/) | Álbumes y artistas — vinilo, CD, digital |
| [Biblioteca de libros](/features/libraries/books/) | Libros con progreso de lectura y seguimiento de sagas |
| [Biblioteca de películas](/features/libraries/movies/) | Películas y series con importación de IMDb |
| [Biblioteca de juegos](/features/libraries/games/) | Videojuegos y juegos de mesa |
| [Biblioteca de recetas](/features/libraries/recipes/) | Recetas con ingredientes y tipos de comida |
| [Biblioteca de citas](/features/libraries/quotes/) | Citas de libros, personas, películas y más |
| [Biblioteca de enlaces](/features/libraries/links/) | Marcadores y URLs guardadas |
| [Biblioteca de plantas](/features/libraries/plants/) | Plantas de interior y de jardín |

## Funciones comunes

Todas las bibliotecas comparten las mismas capacidades principales (allí donde tienen sentido para ese tipo de contenido):

### Búsqueda y filtros

- **Búsqueda** — busca en los campos clave de la biblioteca (por ejemplo, título y artista para música, título e ingredientes para recetas). Pulsa **Ctrl+F** para centrar la barra de búsqueda.
- **Filtros** — filtra por **género**, **valoración**, **lista de deseos** y filtros específicos de cada biblioteca, con un botón para borrar todos.

### Géneros

Cada biblioteca tiene su propio sistema de géneros. Puedes personalizar los géneros — añadirlos, renombrarlos y eliminarlos — para adaptarlos a cómo piensas tu colección. Asigna uno o varios géneros a cualquier entrada.

### Valoraciones y lista de deseos

- **Valoraciones** — valora cualquier entrada en una escala de 1 a 5
- **Lista de deseos** — marca las entradas que quieres y fíltralas

### Vistas

La mayoría de las bibliotecas ofrecen un selector de vistas: **Lista** y **Tarjetas**. Las bibliotecas de **Música** y **Libros** añaden dos vistas 3D:

- **Estantería** — una estantería de madera con las portadas expuestas
- **Lomo** — portadas dispuestas como lomos de libro/disco, con un giro 3D al pasar el cursor; el ancho del lomo de los libros se calcula a partir del número de páginas

### Enlaces externos

Cuando una entrada proviene de un servicio externo, un acceso directo "Buscar en / Ver en" enlaza de vuelta a ese proveedor.

### Imágenes de portada

Cada biblioteca admite imágenes de portada — carátulas de álbum, portadas de libro, pósteres de película, fotos de plantas, etc. Sube las tuyas propias o deja que solyto las obtenga automáticamente del servicio de importación.

### Etiquetas

Añade etiquetas de color a cualquier entrada. Las etiquetas se comparten entre funciones, así que una etiqueta que crees en una biblioteca funciona igual en todas partes.

### Exportar como CSV

Descarga tus datos en cualquier momento como archivo `.csv`. Tus datos siguen siendo tuyos. Consulta [Exportar datos](/integrations/exporting/).

## Recomendaciones con IA

Las bibliotecas de **Música** y **Libros** ofrecen recomendaciones impulsadas por una API compatible con OpenAI. Cuando solicitas una, elige entre:

- **Un favorito** — algo parecido a lo que ya te encanta
- **Algo que no haya visto antes**
- **Algo completamente aleatorio**
- **Algo nuevo**

solyto entonces elige una entrada de tu biblioteca (para "nuevo", busca un lanzamiento reciente vía Deezer/Hardcover). Usa "Probar de nuevo" para repetir la selección. Las recomendaciones se generan solo bajo demanda — no ocurre nada hasta que haces clic en el botón. Consulta [Biblioteca de música](/features/libraries/music/) y [Biblioteca de libros](/features/libraries/books/) para más detalles.

## Notificaciones de lanzamientos

solyto puede avisarte cuando artistas o autores de tu biblioteca publiquen algo nuevo. Las notificaciones de lanzamiento están disponibles para:

- **Música** — nuevos álbumes y sencillos de tus artistas
- **Libros** — nuevos libros de tus autores
- **Películas** — nuevos estrenos relacionados con tu biblioteca

Las notificaciones son configurables por canal (Telegram, correo electrónico, push). Consulta [Notificaciones](/customization/notifications/) para la configuración.

## Importar desde servicios externos

Puedes buscar en línea e importar desde servicios externos como Deezer, Discogs, Goodreads, Hardcover, IMDb, TMDB, Steam, BoardGameGeek y Chefkoch. Las importaciones solo ocurren cuando tú las activas explícitamente — solyto nunca obtiene datos de servicios de terceros en segundo plano. Consulta [Importar datos](/integrations/importing/) para más detalles.
