La Biblioteca de citas es una colección personal de citas — de libros, personas, películas, o de cualquier lugar donde encuentres palabras que resuenen contigo. Guárdalas todas en un mismo lugar donde puedas buscarlas.

## Añadir citas

Añade citas manualmente. Rellena el texto, atribúyela a un autor y, opcionalmente, anota dónde la encontraste.

## Campos de la entrada

Cada entrada de cita incluye:

| Campo | Descripción |
|-------|-------------|
| **summary** | Título o etiqueta breve para la cita |
| **author** | Quién la dijo o la escribió |
| **quote** | El texto completo de la cita |
| **source** | Dónde la encontraste (título del libro, película, persona, etc.) |
| **tags** | Etiquetas de color para filtrar |

## Cita aleatoria

Una cita aleatoria de tu biblioteca alimenta la sección **Inspiración** de tu [panel](/dashboard/overview/) — una cita distinta cada vez que la visitas.

## Vistas y filtros

Explora tus citas en las vistas **Lista** o **Tarjetas**. Busca por palabra clave para encontrar una cita concreta.

## Exportar

Exporta toda tu biblioteca de citas como `.csv`. El archivo incluye todos los campos — texto de la cita, autor y fuente. Consulta [Exportar datos](/integrations/exporting/).
