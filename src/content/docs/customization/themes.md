title: Themes

---

solyto comes with several built-in themes that change the look and feel of the entire interface.

## Changing your theme

Go to **Settings → Appearance → Theme** and select a theme. The change is applied immediately.

## Available themes

| Theme | Description |
|-------|-------------|
| **Default** | Clean, minimal light theme |
| **Dark** | Dark mode version of the default |
| **Skyrim** | Inspired by the UI of The Elder Scrolls V: Skyrim |
| **Paper** | A paper-like, warm, low-contrast look |
| **Atari** | Over-the-top retro style inspired by early Atari interfaces |

## Dark mode

The default theme respects your OS dark mode setting. You can override this in **Settings → Appearance**.

## How themes work

Themes are implemented as CSS variable overrides. They change colors, fonts, and some layout details across the entire app — including the navigation, cards, buttons, and typography.
