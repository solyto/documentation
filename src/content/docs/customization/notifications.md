solyto can send notifications through three channels: Telegram, email, and browser push notifications.

## Notification types

| Notification | Description |
|-------------|-------------|
| Daily digest | Morning summary of your day (todos, events, weather) |
| Upcoming events | Reminders before calendar events |
| Todo reminders | Alerts for due or overdue todos |
| New releases | New music or books from followed artists/authors |
| Export ready | When a data export job completes |
| Plant reminders | Watering and fertilizing reminders |

## Channels

### Telegram

Requires [Telegram Bot setup](/integrations/telegram/). Once connected, you can route any notification type to Telegram. Configure the daily digest time and content in **Settings → Notifications → Telegram**.

### Email

Configure your email notification preferences in **Settings → Notifications → Email**. Choose which notification types to receive and at what frequency.

### Browser push

Enable push notifications in **Settings → Notifications → Push**. Your browser will prompt for permission. Push notifications work even when solyto is not open in a browser tab (if installed as a PWA).

## Configuring notifications

Go to **Settings → Notifications** to:

- Enable or disable each notification type per channel
- Set delivery times for the daily digest
- Configure which sections appear in the digest
