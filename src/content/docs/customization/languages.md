solyto supports multiple interface languages. Change your language in **Settings → General → Language**.

## Changing language

1. Go to **Settings → General**
2. Select your preferred language from the **Language** dropdown
3. The interface updates immediately

## Available languages

solyto is community-translated. The currently available languages are listed in the language dropdown in settings.

## Contributing translations

If your language is missing or incomplete, contributions are welcome. Translation files are in the [app repository](https://github.com/solyto/app) under `src/lib/i18n/`.
